# refimage C API

`librefimage_c` exposes [`refimage`](../refimage) to C, C++ and anything with a C FFI
(C#, Julia, Go, MATLAB, LabVIEW, ...). The API covers images with metadata, the
processing pipeline with every op (debayer, luma, scale, convert, crop/ROI,
flips/rotations, resize, homography warp, `map_coordinates`), compiled runners that
reuse their buffers, bincode (de)serialization, FITS output and the optimum-exposure
calculator.

- Header: [`include/refimage.h`](include/refimage.h). It is generated by cbindgen and
  committed; every declaration is documented there.
- Libraries: shared `librefimage_c.so.1` / `librefimage_c.1.dylib` / `refimage_c.dll`
  and static `librefimage_c.a` / `refimage_c.lib`.

## Build and install

```sh
cargo build --release -p refimage-capi              # target/release/librefimage_c.*
crates/refimage-capi/install.sh /usr/local          # header, libs, pkg-config, CMake
```

`install.sh` installs into `PREFIX` (default `/usr/local`) and honours `DESTDIR`. It
installs:

- `include/refimage.h`
- `lib/librefimage_c.a`
- the versioned shared library plus a `librefimage_c.so` / `.dylib` symlink
- `lib/pkgconfig/refimage.pc`
- `lib/cmake/refimage/`

On Windows, take `refimage_c.dll`, `refimage_c.dll.lib` (import library) and
`refimage_c.lib` (static) from `target/release`.

Use the installed library like this:

```sh
cc app.c $(pkg-config --cflags --libs refimage)                 # shared
```

```cmake
find_package(refimage 1.0 REQUIRED)
target_link_libraries(app PRIVATE refimage::refimage)           # or refimage::refimage_static
```

A static link also needs the system libraries listed at the top of the header. The
CMake target `refimage::refimage_static` adds them for you. With pkg-config, link the
archive (`$prefix/lib/librefimage_c.a`) and add the `Libs.private` libraries that
`pkg-config --static --libs refimage` lists.

## Example

The full program is [`examples/c/stream.c`](examples/c/stream.c); build it with its
[`Makefile`](examples/c/Makefile) (`make`, or `PKG_CONFIG_PATH=<prefix>/lib/pkgconfig make`
for a non-system install), which links it both shared and static.
[`examples/cpp/stream.cpp`](examples/cpp/stream.cpp) does the same in C++17, with RAII
handles (`std::unique_ptr` with the `ref_*_free` deleters) and exceptions for errors. It
builds with CMake through the installed package
(`cmake -S examples/cpp -B build -DCMAKE_PREFIX_PATH=<prefix>`). This is the core of the C
version:

```c
#include <refimage.h>

#define CHECK(call) do { if ((call) != REF_OK) { fprintf(stderr, "%s\n", ref_last_error()); exit(1); } } while (0)

RefFrame frame = {0};                   /* the caller's pixels; never copied for a run */
frame.data = raw;                       /* uint16_t[1080][1920] from the camera SDK */
frame.width = 1920;
frame.height = 1080;
frame.pixel_type = REF_PIXEL_U12;
frame.color = REF_COLOR_BAYER_RGGB;

RefPipeline *p = NULL;
CHECK(ref_pipeline_new(&p));
CHECK(ref_pipeline_debayer(p, REF_DEMOSAIC_LINEAR));
CHECK(ref_pipeline_to_luma(p));
CHECK(ref_pipeline_convert(p, REF_PIXEL_U8));

RefRunner *runner = NULL;
CHECK(ref_pipeline_compile(p, &frame, NULL, &runner));     /* allocates once */
RefImage *out = NULL;
for (;;) {
    wait_for_frame(raw);
    CHECK(ref_runner_run(runner, &frame, &out));  /* first call creates `out`, then reuses it */
}
```

## Conventions

- **Errors.** Every fallible call returns a `RefStatus`, where `REF_OK` is `0`.
  `ref_last_error()` gives the calling thread's last message. Out-parameters are
  written only on success. A Rust panic becomes `REF_ERR_PANIC` and never crosses
  into C.
- **Annotations.** Every pointer carries Clang's nullability qualifier, `_Nonnull`
  or `_Nullable`, so with Clang a literal `NULL` into a required pointer is a
  `-Wnonnull` warning. On compilers without nullability support the header defines
  both as nothing. A `NULL` that slips through at run time is still caught and
  returned as `REF_ERR_NULL`. Every function that returns a value is `_MustUse`, so
  an ignored `RefStatus` warns. That is `[[nodiscard]]` in C23 and C++17,
  `warn_unused_result` on GCC and Clang, and `_Check_return_` on MSVC. Define
  `_MustUse` before including the header to override it.
- **Handles.** `RefImage`, `RefPipeline` and `RefRunner` are opaque. Each has a
  `*_free` that accepts `NULL`. A handle may move between threads, but must not be
  used by two threads at once.
- **Enumerations** are `uint32_t` values with `REF_*` constants. An unknown value is
  rejected with `REF_ERR_INVALID_ARG`; it is never undefined behaviour.
- **Strings out** use the `(buf, buf_len, out_len)` pattern. Pass
  `buf = NULL, buf_len = 0` to query the length.
- **Blobs out** (bincode, FITS, JSON) come back as a `RefBuffer`. Release it with
  `ref_buffer_free`.
- **Pipelines** can be built with the typed `ref_pipeline_*` functions, or from the
  JSON that Rust and Python produce (`ref_pipeline_from_json` / `ref_pipeline_to_json`).
- **Frames** are borrowed. Padded rows (`row_stride`) are packed into a staging
  buffer that the runner reuses.

## Allocation

With a serial strategy (`RefStrategy.parallel = false`), a compiled runner allocates
nothing per frame in these calls:

- `ref_runner_run` into an existing image
- `ref_runner_run_into` a caller buffer
- `ref_runner_run_image`, provided the input has no extra metadata cards

[`tests/alloc.rs`](tests/alloc.rs) checks this.

## ABI

`REF_ABI_VERSION` (compile time) and `ref_abi_version()` (run time) identify the
binary interface. Any incompatible change to a signature, struct layout or constant
increments the ABI version. The shared library's soname or install name carries the
same number, so a program never loads an incompatible library.

## Development

```sh
cargo test -p refimage-capi                                   # Rust tests + the C test program
REFIMAGE_BLESS=1 cargo test -p refimage-capi --test header   # regenerate include/refimage.h
```

The header generator in [`tests/header.rs`](tests/header.rs) adds the nullability
annotations. A parameter is `_Nullable` when its doc comment says "`name` may be
`NULL`", and a field when its doc says "May be `NULL`". A few fixed rules cover
`*_free` arguments, string-out buffers and handle out-slots. Everything else is
`_Nonnull`. Test-only compile checks confirm that an ignored status, and (with
Clang) a `NULL` passed to a required pointer, each fail to compile.

`tests/c_api.rs` compiles [`tests/c/test_api.c`](tests/c/test_api.c) with `$CC`
against the libraries that were just built, both static and shared. On Linux it also
builds and runs an AddressSanitizer + LeakSanitizer + UBSan copy.
